# 🛍️ ShopEasy

ShopEasy is a simple e-commerce website built with a premium and modern design.

## ✨ Features

- Product listing
- Product details
- Men, Women and Unisex categories
- Product search
- Product type filtering
- Shopping cart
- Quantity management
- Checkout page
- User registration
- User login
- Stock availability
- Oracle Database integration
- REST API using Node.js and Express
- Responsive frontend design

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Google Fonts

### Backend

- Node.js
- Express.js
- OracleDB

### Database

- Oracle Database
